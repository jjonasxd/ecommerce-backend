## 🛠️ Back-end Tecnologias Utilizadas

* **Flask - Python 3.xx**
* **Resend - Serviço de email**
* **Mysql - Banco de dados**

---

## ✨ Funcionalidades da API

- [x] Cadastro de usuários
- [x] Login
- [x] Autenticação por email, via JWT
- [x] OTP (One-Time-Password)
- [x] Criptografia e Hash
- [x] Perfil interativo
- [ ] Cadastro de produtos (*Desenvolvimento*)
- [ ] Simulação de compra
- [ ] Carrinho (*Desenvolvimento*)
